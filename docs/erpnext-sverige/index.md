# ERPNext Sverige

![ERPNext Sverige](../assets/logo/erpnext-sverige.svg#only-light){ width="420" }
![ERPNext Sverige](../assets/logo/erpnext-sverige-dark.svg#only-dark){ width="420" }

Appen **ERPNext Sverige** anpassar bokföring, fakturering och betalningar för svenska bolag, utan att ändra i
ERPNext:s egen kod. Källkoden finns på [GitHub](https://github.com/ubbe76/ERPNext-Sverige) under GPL-3.0.

| Sida | Innehåll |
|---|---|
| [Installation och backup](installation.md) | Installation på en befintlig site, grunduppsättning av bolaget och backup |
| [Bokföring och moms](bokforing.md) | BAS-kontoplan, momskategorier, automatiskt kontoval, momsdeklaration, grundbok och SIE |
| [Fakturering](fakturering.md) | Fakturamallen, momsregistreringsnummer, OCR och fakturanummer utan luckor |
| [Betalningar](betalningar.md) | Bankgiroinbetalningar (BgMax) och leverantörsbetalningar (pain.001) |
| [Bokslut och arkiv](bokslut-och-arkiv.md) | Årsarkiv enligt bokföringslagen |
| [Systemdokumentation](systemdokumentation.md) | Systemdokumentation och behandlingshistorik enligt bokföringslagen |

Transportbokning finns i den separata appen [ERPNext Sverige Frakt](../frakt/index.md).
